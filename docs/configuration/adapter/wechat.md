# WeChat Adapter

KiraAI uses the WeChat ClawBot API to communicate with WeChat. This adapter only supports private chats.

For detailed documentation, refer to the [WeChat ClawBot API Reference](https://developers.weixin.qq.com/doc/aispeech/knowledge/openapi/Clawbotrelated.html)

## Add Adapter

In the KiraAI WebUI sidebar, click Adapters, then click "Add Adapter" and select Personal WeChat. No configuration below needs to be modified.

After saving, go to the System Logs in the sidebar, find the URL corresponding to the QR code, open it in a browser, scan the code, and confirm the binding on your phone.
