# 聊天设置

聊天设置控制 KiraAI 如何保留上下文、合并连续消息、发送回复，以及是否启用图片、语音和生成等能力。它们是全局默认值；可以在**会话管理**中为单个会话覆盖部分能力开关。

## 开始前

1. 先在[提供商配置](/zh/configuration/provider)中添加可用模型。
2. 打开 WebUI 的 **配置项 → 模型**，至少选择一个**默认大语言模型**；它是普通文本对话所必需的主模型。
3. 如需图片理解、语音识别、语音合成、图片或视频生成，也在该处分别选择默认 VLM、STT、TTS、图片或视频模型。
4. 打开 **配置项 → 数字生命 → 聊天设置**，按下文调整全局聊天行为并保存。

## 上下文与消息节奏

建议先保留默认值，只有在实际对话中遇到上下文不足、回复过碎或响应节奏不合适时再调整。

| 设置 | 默认值 | 配置建议 |
| --- | --- | --- |
| 最大上下文长度 | 10 条消息 | 控制每个会话保留的消息数量。增大可保留更多上下文，但会提高模型输入量、延迟和费用；缩小可降低开销。 |
| 溢出丢弃数量 | 1 条消息 | 上下文超过上限时，每次移除最早的消息数。通常保持为 1；若上下文上限很大且希望更快释放空间，可适度提高。 |
| 消息合并间隔 | 2 秒 | 收到消息后等待的时间；在此窗口继续收到的消息会合并处理。较短更灵敏，较长更适合用户习惯连续分段发送消息的场景。 |
| 最大缓冲消息数 | 5 条 | 单次处理前允许累积的最多消息数。达到上限会尽快处理，避免大量连续消息无限等待。 |
| 最小/最大消息延迟 | 2 / 5 秒 | 控制连续发送回复消息之间的随机延迟区间。需要更快发送可降低数值；不要将最大值设得小于最小值。 |

## 提示词与记忆注入位置

**动态内容位置**决定会话列表、聊天环境和时间等动态信息放在哪里；**记忆注入位置**决定核心记忆放在哪里。两项都可选“系统提示词”或“最新用户消息”。

通常建议选择**最新用户消息**：系统提示词能够保持稳定，兼容提示词缓存的模型更容易命中缓存。只有模型或自定义提示词明确要求将这些内容放入系统提示词时，才改为“系统提示词”。

## 聊天能力

在 **配置项 → 数字生命 → 能力设置** 中按实际已配置的模型启用功能。

| 功能 | 何时启用 | 配置要点 |
| --- | --- | --- |
| 图片识别 | 希望机器人理解聊天中的图片或表情包时。 | **VLM 描述**会先用默认 VLM 将图片转换为文字描述；**原生多模态**会把图片直接交给主 LLM，因此主 LLM 必须支持图片输入。自定义描述提示词留空时使用内置提示词。 |
| 语音识别（STT） | 希望将收到的语音转为文字时。 | 需要选择默认 STT 模型。 |
| 语音合成（TTS） | 希望机器人能够发送语音回复时。 | 需要选择默认 TTS 模型。 |
| 图片/视频生成 | 希望通过文本生成图片或视频时。 | 分别需要默认图片或视频模型；未配置相应模型时请关闭能力。 |
| 解析转发消息 | 希望机器人读取转发内容时。 | 关闭后，转发消息仅保留占位信息，可减少处理量。 |

## Agent 与图片压缩

**Agent 设置**限制单次回复中的工具执行规模：默认最多 5 轮 Agent 循环、每轮最多 5 次工具调用，单次工具调用默认超时 60 秒。提高这些上限可能让复杂任务完成更多步骤，但会增加响应时间、模型调用和工具调用成本；将工具调用超时设为 `0` 表示不设置超时，应仅在可信且可控的工具环境中使用。

**图片压缩**默认关闭。启用后，过大或分辨率过高的入站图片会在发送给 VLM 或原生多模态模型前压缩。默认最长边为 1280 像素、JPEG 质量为 95、文件阈值为 1 MB。带宽或模型输入成本受限时可启用；需要识别细小文字或细节时，应保持关闭或提高最长边与质量。

## 聊天插件配置

除全局设置外，聊天行为还由聊天插件配置。内置且默认使用的插件是 **默认聊天**（`default-chat`）：它负责合并即时通讯消息，并决定未提及机器人的群消息如何参与上下文。

在 WebUI 的 **附加功能 → 插件** 中打开 **默认聊天** 的配置。你也可以从 KiraAI 插件商店 安装第三方聊天插件；若启用了其他聊天插件，请以该插件自己的配置说明为准。

| 设置 | 默认值 | 配置建议 |
| --- | --- | --- |
| 唤醒词 | 空 | 消息包含任一唤醒词时会被视为提及机器人。适合无法使用 `@` 提及或希望设置昵称唤醒的场景。避免使用过于常见的词，以免误触发。 |
| 接收未提及消息 | 关闭 | 开启后，未提及机器人的消息会作为上下文缓冲；它们不会因为这一设置本身而必然触发回复。群聊较嘈杂或不希望读取旁人对话时，保持关闭。 |
| 最大未提及消息数 | 5 条 | 限制进入上下文缓冲的未提及消息数量。仅在开启“接收未提及消息”后调整。 |
| 群聊提示词 | 空 | 追加到群聊的聊天环境提示词，用于规定群聊语气、参与方式或边界。只写群聊专属规则，通用人设请在 Persona 中配置。 |
| 群聊主动发言 | 关闭 | 允许机器人基于未提及消息主动在群内发言。仅在已开启“接收未提及消息”且已取得群成员同意时启用。 |
| 主动发言概率 | 0.1 | 每次满足条件时触发主动发言的概率。先使用较低数值，观察频率后再提高。 |

修改聊天插件配置后保存；为确保消息合并等初始化时读取的参数生效，重启 KiraAI 后再测试。

## 会话级覆盖与生效检查

在 **会话管理** 中编辑某个会话，选择“自定义能力”即可为该会话单独开关图片识别、STT、TTS、图片/视频生成和转发解析；选择“全局”则沿用本页的默认设置。

点击 **保存** 后设置会写入运行时配置。发送一条新的测试消息验证效果；消息合并、发送延迟等在组件启动时读取的设置，为确保生效请重启 KiraAI 后再测试。更多由消息插件提供的聊天选项，请到 **附加功能 → 插件** 中查看已启用插件的配置。
