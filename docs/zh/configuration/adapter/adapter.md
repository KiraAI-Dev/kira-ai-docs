# 适配器配置

适配器将 KiraAI 连接到聊天和社交平台：它接收平台消息、交给 KiraAI 处理，并将回复发送回原会话。每个适配器实例保存自己的平台凭据、连接地址和访问规则；同一平台可创建多个实例。

## 添加适配器

1. 在 WebUI 中打开 **适配器**，点击 **添加适配器**。
2. 填写唯一的实例名称，并选择平台类型。名称会用于会话标识，不能包含英文冒号（`:`）。
3. 按页面动态显示的字段填写该平台的连接信息和访问规则。字段由所选适配器或已启用插件提供。
4. 保存配置。启用开关后，KiraAI 会启动该适配器；编辑已启用适配器的名称、说明或配置时，会自动重新加载其实例。
5. 在 **日志** 页面确认平台已成功登录或开始监听消息。

::: warning 保护凭据
Bot Token、App Secret、WebSocket Token，以及 BiliBili Cookie 等均属于敏感信息。不要将它们写入截图、日志或共享配置文件；若怀疑泄露，请立即在对应平台撤销并重新生成。
:::

## 内置适配器

| 平台类型 | 用途与接入方式 | 主要配置 |
| --- | --- | --- |
| QQ | 通过兼容 OneBot 的 QQ 协议端接入 QQ。 | 机器人 QQ 号、WebSocket 地址和 Token，以及群聊/私聊白名单或黑名单。详见 [QQ 适配器](./qq)。 |
| QQ 官方机器人 | 通过 QQ 机器人开放平台接入群聊和好友私聊。 | AppID 与 AppSecret；也可将两项同时留空，启用后通过手机 QQ 扫码绑定。可选沙箱模式与访问列表。 |
| Telegram | 通过 Telegram 官方 Bot 接收和发送私聊、群聊消息。 | Bot 用户名、由 `@BotFather` 创建的 Bot Token，以及群组/用户访问列表。详见 [Telegram 适配器](./telegram)。 |
| Discord | 通过 Discord Bot 接入频道和私信。 | Discord Developer Portal 的 Bot Token、Gateway Intents、可选 HTTP 代理、频道/用户访问列表；可配置斜杠命令同步范围。 |
| BiliBili | 监听指定 B 站视频的评论。 | 机器人 UID、要监听的视频 BVID、轮询与消息处理间隔，以及从浏览器 Cookie 或 LocalStorage 获取的登录字段。详见 [BiliBili 适配器](./bilibili)。 |
| 个人微信 | 通过 OpenClaw API 接入个人微信私聊。 | 默认 API 与 CDN 地址通常无需修改；保存并启用后，按日志中的二维码链接扫码绑定。此适配器不支持群聊。详见 [微信适配器](./wechat)。 |

适配器下拉列表还会显示由已启用插件注册的平台类型。它们的字段和登录方式由插件决定，请以插件说明为准。

## 访问规则

QQ、QQ 官方机器人、Telegram、Discord 和个人微信适配器都提供访问控制；不同平台可用的群组、频道或用户字段略有不同。

- **白名单（allow list）**：仅响应列表中的用户、群组或频道。
- **黑名单（deny list）**：忽略列表中的用户、群组或频道。

请在启用适配器前确认当前模式和 ID 列表。平台所要求的 ID 可能是 QQ 号、OpenID、Telegram 用户或群组 ID，或 Discord 用户、频道与服务器 ID；不要用显示昵称替代平台 ID。

## 测试与排查

保存并启用后，向机器人发送一条测试消息，并在 **日志** 页面查看平台的登录、连接或监听记录。

1. 确认实例名称唯一，且不含 `:`。
2. 重新核对 Token、AppID/AppSecret、WebSocket 地址、代理地址和 Cookie 是否来自同一机器人或账号。
3. 核对平台后台的权限设置。例如，Discord 需要启用所选 Gateway Intents；QQ 的 OneBot 协议端需要提供可连接的 WebSocket 服务。
4. 检查白名单或黑名单中的平台 ID 是否正确，以及是否选择了预期的访问模式。
5. 修改已启用实例的配置后，等待其自动重载；若仍无法连接，先停用再启用，并查看日志中的具体错误。

如需为新的聊天平台开发适配器，请参阅[适配器开发](/zh/development/adapters)。
