# WebUI 使用指南

KiraAI WebUI 是实例的管理面板，用于完成首次配置以及管理提供商、适配器、人设、插件、会话和日志。

## 访问 WebUI

启动 KiraAI 后，在浏览器中打开启动日志输出的地址。默认情况下，WebUI 使用 `5267` 端口：

```text
http://127.0.0.1:5267
```

监听地址和端口保存在 `data/webui.json` 中，默认值为 `0.0.0.0` 和 `5267`。通过局域网地址或反向代理访问时，请使用日志中显示的对应地址。

WebUI 默认受访问令牌保护。KiraAI 启动时会在终端日志中输出当前访问令牌；出现登录页时，将该令牌填入即可。令牌可获得该实例的管理权限，请妥善保管；网络可访问的部署不要关闭 WebUI 认证。

## 首次配置

首次打开 WebUI 会进入引导流程，建议按以下顺序完成：

1. 添加提供商，并至少配置一个 LLM 模型。
2. 在 **配置** 中选择默认模型。
3. 创建或选择一个人设。
4. 添加并启用聊天平台适配器。

随后在 **日志** 页面确认提供商和适配器已成功连接。具体配置请参阅[提供商配置](/zh/configuration/provider)和[适配器配置](/zh/configuration/adapter/qq)。

## 主要页面

| 页面 | 可执行的操作 |
| --- | --- |
| **概览** | 查看服务状态和插件提供的仪表盘组件。 |
| **提供商** | 添加提供商、配置模型，并对支持的模型执行健康检查。 |
| **适配器** | 配置和启用聊天平台连接。 |
| **人设** | 创建和管理对话使用的人设。 |
| **表情包** | 管理本地表情包库。 |
| **配置** | 设置全局选项，包括默认模型和网络相关配置。 |
| **附加功能** | 管理已安装插件、插件商店、MCP 服务器、Skills 及其会话范围。 |
| **会话** | 查看和管理对话会话。 |
| **日志** | 查看运行日志，排查连接或配置错误。 |
| **设置** | 管理 WebUI 设置和应用提供的实例数据操作。 |

侧边栏底部的语言选择器可在中文和 English 之间切换 WebUI 语言；插件页面也可以提供自己的本地化标签。

## 安全使用

- 保存配置后，再启用相应的提供商、适配器、MCP 服务器或插件。
- 插件包、Skills 压缩包、MCP 服务器定义和提供商端点均应视为受信任的代码或服务输入；添加前请核查其来源和权限。
- 配置未生效时，先刷新对应列表、查看 **日志**，再确认项目是否已启用。
- 升级或进行较大配置变更前，请备份 `data/` 目录。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 无法打开 WebUI | 确认 KiraAI 正在运行，并检查启动日志和 `data/webui.json` 中的地址与端口。 |
| 登录页不接受令牌 | 使用当前启动日志中的令牌，或在 **设置** 中更新令牌；不要混用其他实例的令牌。 |
| 页面没有数据 | 确认已完成引导，刷新页面，并在 **日志** 中查看后端错误。 |
| 远程设备无法连接 | 检查监听地址、防火墙和反向代理配置，使用启动时打印的局域网地址；请保持认证开启。 |
