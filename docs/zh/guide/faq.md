# 常见问题

## 通用问题

::: details 为什么后台显示 AI 回复了但是没有收到消息？
这是一个常见问题，通常由以下原因导致：

1. **AI输出格式错误** — KiraAI 要求 AI 格式化输出 XML 内容构造消息链，错误的 XML 格式可能导致无法正确发送消息。尤其是 DeepSeek V4 模型容易不使用或使用错误的 XML 格式。

2. **适配器消息发送失败** — AI 成功生成了回复，但适配器在将消息投递到聊天平台时失败了。请检查适配器日志中是否有消息发送相关的错误信息。

3. **消息被平台过滤或限流** — 部分聊天平台有内容审核或频率限制策略，消息可能被平台静默丢弃。可以尝试发送一条更简单的消息进行测试。

4. **机器人权限不足** — 机器人账号可能缺少在当前群组或会话中发送消息的权限。请确认机器人已获得必要的权限。

5. **网络问题** — 机器人与聊天平台之间的网络中断可能导致消息投递失败。请检查网络连接后重试。
:::
